# 知识库页面 UI 文本规范迁移

## 目标

知识库页面所有用户可见文本统一使用简洁、直观的中文；后端接口枚举值、路径、ID 和检索协议字段保持原值。

## 本轮范围

- 知识库、文档、版本、内容分片
- 版本处理与处理结果
- 知识检索调试
- 检索方式、相关度、检索来源、引用位置
- 混合检索评分明细
- 创建、删除、错误和空状态提示

## 文本规则

| 技术概念 | 用户界面统一表达 |
| --- | --- |
| Knowledge | 知识库 |
| Document | 文档 |
| Version | 版本 |
| Chunk | 内容分片 |
| Ingestion | 处理 |
| Retrieval | 检索 |
| Retrieval Debug | 知识检索调试 |
| Score | 相关度 / 评分 |
| Citation | 引用位置 |
| Source URI | 来源地址 |
| Hybrid | 混合检索 |
| Vector | 向量检索 |
| Lexical | 关键词检索 |

## 保留技术值

`lexical-v2`、`vector`、`hybrid`、`manual` 等接口枚举仅作为请求参数或数据模型值保留，不作为页面标题、说明或操作按钮使用。

## 回归要求

知识库页面测试必须覆盖：

1. 页面标题和核心区域均为中文。
2. 检索方式使用中文名称展示。
3. 检索结果包含相关度、引用位置和检索来源。
4. 混合检索能够展示评分明细。
5. 检索输入为空时不请求后端并提示用户。
6. 后续新增用户可见文本不得直接引入英文技术术语。
