# 前端用户可见文本统一：Knowledge / Agent / Organization

## 目标

在不改变既有页面结构、接口契约和业务行为的前提下，统一用户可见文本为通俗易懂的中文；后端状态、错误码、请求标识等技术标识继续保留，用于排障和运维。

## 本轮完成

### Agent

- 智能体生命周期状态统一中文：草稿、已发布、已归档、已启用、已停用。
- 未知状态不再裸显示，采用“未知状态（原始值）”。
- 列表加载、创建、版本管理、发布、归档、对话执行等错误统一经过用户提示归一化。
- HTTP 4xx/5xx 原始错误不直接作为用户提示；使用中文兜底文案。
- 请求标识、链路追踪标识、会话标识、执行标识保持中文标签，同时保留技术 ID。

### Organization

- 组织状态统一为“已启用 / 已停用”；未知状态显示“未知状态（原始值）”。
- 组织列表与创建操作的 HTTP 错误不直接展示原始错误文本。
- 保留“租户 ID”等技术标识，避免为了中文化丢失排障信息。

### Knowledge

源码扫描确认仍需继续处理以下用户可见技术词：

- Knowledge
- Chunk / Chunks
- Ingestion / Ingest
- Retrieval Debug
- Lexical / Vector / Hybrid
- Score / Mode / Sources / Citation
- Document / Source URI
- `status` / `ingestion_status` 的直接枚举展示
- API 异常中的 `error.message` 直接展示

处理原则：中文作为主要界面文本，必要时使用“中文说明（技术标识）”形式保留后端契约值。

## 回归测试要求

每个页面至少覆盖：

1. 正常状态的中文显示。
2. 未知状态的中文兜底。
3. HTTP 错误不直接展示给用户。
4. 技术 ID / 错误码仍可追踪。
5. 页面结构和业务操作不发生变化。

## 后续

Knowledge 页面完成源码级中文化后，再进行全量前端源码扫描，重点检索：`error.message`、`status`、`error_code`、英文枚举和英文用户提示，避免新增页面重新出现中英文混用。
