# 前端用户可见文本统一：组织、模型提供商、审计、Runtime

## 本轮范围

本轮继续沿用“现有页面扫描 → 用户可见文本中文化 → 保留技术标识 → 中文文案回归测试”的策略，不调整页面结构、交互流程和后端接口。

## 处理原则

1. 用户可见的状态名称使用通俗中文，例如“已启用”“已停用”“运行中”“已完成”“失败”。
2. HTTP 状态、后端异常对象等技术信息不得直接作为用户提示；用户看到明确的中文处理建议。
3. ID、错误代码、提供方类型、模型名称等技术标识保持原值，便于运维定位。
4. 未知后端状态不能直接回显英文枚举，统一显示“未知”。
5. `console.error` 可以保留原始异常，用于开发和运维排查，但不得直接绑定到页面提示。

## 本轮修改

- 组织：列表加载和创建异常统一中文提示；`Tenant ID` 调整为“租户 ID”。
- 模型提供商：加载、保存、删除异常不再直接展示 HTTP 错误；`Dimension` 调整为“向量维度”。
- 审计：状态枚举统一映射为中文，未知值显示“未知”。
- Runtime：时间线和工作流链路中的状态统一复用 Runtime 状态中文映射；查询异常增加用户可执行的中文提示。

## 回归要求

新增或修改页面时，应至少覆盖：成功状态、失败状态、进行中状态、未知状态，以及 HTTP 异常不直接透传到页面的场景。
