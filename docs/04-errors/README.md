# 工程错误记录

本目录是新的唯一工程错误记录入口。

## 命名

```text
ERR-0001-description.md
ERR-0002-description.md
```

## 迁移

旧 `docs/error-tracking/` 中存在历史错误记录，并且旧编号存在重复。迁移时：

1. 保留原文件事实。
2. 分配唯一 `ERR-####`。
3. 在文件中保留 `Legacy ID`。
4. 不修改历史错误的实际结论。
5. 测试结果不得根据计划补写。

## 必备字段

- 发生阶段
- 发生时间（若来源有记录）
- 命令 / 入口
- 实际错误
- 根因
- 影响
- 修复方案
- 实际验证结果
- 防重复措施
- 状态
